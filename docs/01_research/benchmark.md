## Studied platforms

### Reddit
- Public discussion platform based on threads and comments.
- Users must create an account, even if usernames are pseudonymous.
- Strong moderation system.

**Strengths**
- Large communities
- Threaded discussions
- Voting system improves content visibility

**Weaknesses**
- Account creation required
- Identity persists over time (history)
- Can discourage spontaneous or sensitive posts

---

### 4chan
- Fully anonymous imageboard-style discussions.
- No accounts required.

**Strengths**
- Total anonymity
- Very low barrier to entry

**Weaknesses**
- Poor content organization
- Toxic behavior encouraged by lack of moderation
- Threads disappear quickly

## Differentiation opportunities

- No account creation
- Clean and simple UI
- Thread + comment structure
- Basic moderation tools without user profiles
